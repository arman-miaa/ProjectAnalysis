# Project Analysis Framework

## Goal

প্রতিটি প্রজেক্টে কোড লেখার আগে সম্পূর্ণ Business Analysis, UX Planning, Page Structure, Section Structure, Database Design এবং Development Roadmap তৈরি করা।

---

# Step 1: Understand The Business

## Questions To Ask Client

* এই প্রজেক্টের উদ্দেশ্য কী?
* কারা ব্যবহার করবে?
* ব্যবহারকারীরা কী কী কাজ করতে পারবে?
* Revenue Model কী?
* Competitors কারা?
* Success কিভাবে Measure করা হবে?

## Output

* Business Goal
* Problem Statement
* Solution Statement
* Target Audience

---

# Step 2: Competitor Research

কমপক্ষে 5–10টি Competitor Website/App বিশ্লেষণ করুন।

## Analyze

* Home Page
* Navigation
* Features
* Pricing
* User Flow
* Design Style
* CTA Placement

## Output

* Competitor List
* Strengths
* Weaknesses
* Opportunities
